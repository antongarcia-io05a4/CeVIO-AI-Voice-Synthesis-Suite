## 常見問題（FAQ）

**Q1: 安裝後軟體無法啟動，出現錯誤怎麼辦？**
A1: 請先確認您的系統是 Windows 10 或 11 的 64 位元版本。其次，檢查是否有防毒軟體或防火牆攔截了程式運行，嘗試將其加入白名單。最後，建議以系統管理員身份右鍵點擊軟體捷徑並選擇「以管理員身份執行」。

**Q2: 這個版本與官方版本有什麼不同？穩定嗎？**
A2: 本套件整合了官方核心元件與所有已授權的語音資料庫，旨在提供一站式安裝體驗。其穩定性基於官方公開發行的版本，並經測試能在大多數符合需求的系統上穩定運行。如同所有軟體，建議定期備份您的專案檔案。

**Q3: 安裝後是否還需要輸入序號或啟用？**
A3: 本安裝包已整合了完整的初始化流程。軟體在首次啟動時會進行簡短的線上驗證，以確保使用環境合規。整個過程自動完成，無需使用者手動輸入額外的授權碼。

**Q4: 支援 Windows 7 或 Windows 8 嗎？**
A4: 不支援。本套件明確要求並針對 Windows 10 以及 Windows 11 系統進行開發與測試，較舊的作業系統可能無法提供必要的運行庫或存在相容性問題。
